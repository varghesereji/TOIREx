Setting up
==============

Download the config file from https://github.com/varghesereji/TOIREx/blob/main/src/toirex/config/TOIREX_config.config

or copy it from

.. code-block:: bash
		
		/path/to/env/TOIREx/src/toirex/config/TOIREX_config.config

Keep the config file where the directory which contain the data is saved.

Open the config file in a text editor, and make sufficient changes in it.

Now you are all set to start!!!
